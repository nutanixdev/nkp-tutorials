# Nutanix Kubernetes Platform Tutorials

This repository contains hands-on tutorials, demos, and reference implementations for Nutanix Kubernetes Platform (NKP).

The examples are designed to help platform engineers, Kubernetes administrators, and cloud-native practitioners quickly experiment with Kubernetes platforms, GitOps workflows, AI workloads, observability, networking, storage, and day-2 operations using NKP.

---

# 📚 Available Tutorials

| Tutorial                                                   | Description                                                                                                                                                         |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`deploying-nkp-with-terraform`](./deploying-nkp-with-terraform) | Deploying an NKP Management Cluster using `Terraform` |
| [`ai-cpu-on-nkp-with-localai`](./ai-cpu-on-nkp-with-localai) | Deploy `LocalAI` Inference on any NKP edition to experiment with LLM models |
| [`pgvector-on-nkp-with-cnpg`](./pgvector-on-nkp-with-cnpg) | Deploy PostgreSQL + `pgvector` on NKP using CloudNativePG (CNPG), including GitOps workflows, HelmRelease support, fake vector data, and similarity search examples |
